# 🐉 HYDRA 7 | Site Oficial

**HONRA • UNIÃO • GUERRA**

Site oficial da guilda **HYDRA 7**, desenvolvido para reunir informações da organização, apresentar seus membros e lines, divulgar resultados e campeonatos e receber inscrições para recrutamento.

## 🌐 Acesse o site

- **Site oficial:** https://hydra-7-ofc.github.io/HYDRA7-OFICIAL/
- **Recrutamento:** https://hydra-7-ofc.github.io/HYDRA7-OFICIAL/recrutamento.html

## ⚔️ O que você encontra

- **Início:** apresentação da HYDRA 7.
- **Membros:** jogadores que fazem parte da organização.
- **Lines:** organização das equipes.
- **Resultados:** desempenho e pontuação nas guerras.
- **Campeonatos:** campanhas e colocações.
- **Notícias:** avisos e novidades da guilda.
- **Recrutamento:** formulário para novos integrantes.

## 🛠️ Área administrativa

O projeto possui painéis administrativos para gerenciar os dados do site e analisar inscrições. O acesso é restrito a administradores autorizados.

- admin.html — gerenciamento do site.
- admin-inscricoes.html — análise das inscrições.

## 💻 Tecnologias

- HTML, CSS e JavaScript.
- Supabase para banco de dados e autenticação.
- GitHub Pages para publicação do site.
